# HADRON TRIAD // 3D Creative Engineering Collective

An award-tier, engine-first 3D creative web portfolio engineered with Three.js, React Three Fiber, Lenis smooth scroll, GSAP ScrollTrigger, and Web Audio API procedural sound synthesis.

Showcases the collaborative synergy of **Kunal Sabale**, **Animesh Dabhade**, and **Rajani Mourya**, backed by live GitHub project specimens.

## 🚀 The Triad Collective
- **Kunal Sabale**: Chief Systems Architect & Builder ("The Build") — WebGL 2.0, Three.js, Rust/WASM, performance profiling, and deterministic engineering.
- **Animesh Dabhade**: Creative Strategist & Ideation Lead ("The Idea") — Narrative worldbuilding, spatial scripting, product discovery, and thematic art direction.
- **Rajani Mourya**: Presentation Director & UI Developer ("Presentation & Dev") — High-craft UI/UX engineering, motion typography, and responsive touch ergonomics.

## ⚡ Tech Stack & Architecture
- **Framework**: Vite + React 18 + TypeScript + Tailwind CSS
- **3D Graphics Engine**: Three.js + React Three Fiber + Drei
- **Custom Shaders**: GLSL vertex displacement beam + selective bloom + film grain dithering + chromatic aberration
- **Motion & Scroll**: Lenis inertial smooth scroll + GSAP ScrollTrigger
- **Audio DSP**: Zero-dependency Web Audio API procedural synthesis (48 Hz sub-bass drone, scroll Doppler filter modulation, spatial stereo panning)

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/Kunal-sabale10/Team.git

# Navigate into the project
cd Team

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
